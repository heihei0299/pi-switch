# 网关面板按供应商分组展示

Status: superseded（被 supplier-channel-models spec 取代，遵循 ADR-0008 做渠道分区+二次勾选）

## Problem Statement

网关面板的模型配置区是一张扁平长表：所有模型混排，没有供应商归属信息，行上的暴露开关是无操作的摆设；真正的暴露管理藏在供应商页弹窗里。用户（尤其多供应商用户）无法回答“这个模型是哪个供应商的、发布了没有”，还曾误以为网关只能接单一供应商。聚合语义本身是对的（网关 = 全量供应商暴露集），缺的是按供应商的结构化呈现。

## Solution

网关面板的模型配置区改按供应商分组展示：以各供应商已暴露候选为数据源，每个模型行带发布状态（已发布 / 待发布 / 待移除同步），空暴露供应商显示空组 + 去供应商页勾选的引导；暴露的编辑仍只在供应商页，网关面板只读不写。纯展示层改动，不改聚合语义、不改网关 id 形态、不碰后端。

## User Stories

1. As a 网关管理员, I want to 在网关面板看到模型按供应商分组（组头为供应商名与计数）, so that 一眼知道每个供应商贡献了哪些模型
2. As a 网关管理员, I want to 每个模型行显示发布状态（已发布/待发布/待移除同步）, so that 知道哪些暴露还没同步进网关
3. As a 网关管理员, I want to 空暴露的供应商显示为空组并引导去供应商页勾选, so that 不误以为网关漏接了该供应商
4. As a 网关管理员, I want to 已撤回暴露但网关仍有残留的模型归入待移除同步提示, so that 残留可被发现和清理
5. As a 网关管理员, I want to 分组内保持各供应商的暴露顺序, so that 与供应商页的顺序心智一致
6. As a 网关管理员, I want to 行上不再出现无操作的暴露开关, so that 不被误导去点一个没效果的控件
7. As a 网关管理员, I want to 分组不影响现有的 JSON 编辑与应用到 Pi 流程, so that 发布链路原样可用
8. As a 网关管理员, I want to 组头显示该供应商已发布数与待发布数, so that 单组差异一目了然
9. As a pi 用户, I want to 网关面板改动后网关文件内容与之前一致（同暴露集同输出）, so that 纯展示重构不改变任何落盘行为

## Implementation Decisions

- 数据源：网关预览接口返回的已暴露候选集合为主；逐模型与当前已注入集合比对得出发布状态（一致=已发布，候选有而注入无=待发布，注入有而候选无=待移除同步）
- 分组键：模型 id 的供应商前缀段（`supplier/modelId` 的首段）；前缀缺失或异常的模型归入未分组兜底组，不丢弃
- 空组：暴露集为空的供应商仍列组头，组内为空状态文案 + 跳转供应商页的引导入口
- 只读原则：网关面板不写任何供应商的暴露集；行级暴露开关移除或永久禁用，暴露编辑唯一入口仍是供应商页
- 排序：供应商组按名称排序，组内模型保持暴露候选原有顺序
- 状态条与横幅：现有的 Current vs Proposed 状态条、不一致提示横幅、JSON 编辑区、应用到 Pi 流程全部保留，计数口径不变
- 单一展示 seam：改动收敛在网关面板组件内；预览接口、聚合逻辑、发布写入、代理模型列表均不改

## Testing Decisions

- 只测外部行为：给定预览数据（候选集合 + 已注入集合），断言分组结构、状态标识与空组引导，不测内部实现
- 组件测试：多供应商分组渲染；已发布/待发布/待移除同步三种状态同时出现；空暴露供应商的空组与引导；异常 id 进兜底组；暴露开关不可操作
- 一致性测试：同输入下分组前后的待发布计数与之前一致；落盘内容不受展示改动影响
- 先例：网关面板既有组件测试、网关隔离测试、网关差异工具单测

## Out of Scope

- 渠道级分区（upstream 按 name 主键分区模型池与暴露集、网关 id 加渠道段）
- 网关聚合语义的任何改动（暴露口径、空暴露含义、id 合成规则）
- 发布时二次勾选子集（按供应商/渠道/模型粒度的部分注入）
- 供应商页暴露管理交互的改动
- 后端接口、网关文件格式、代理模型列表的改动
- 对话级统计、费用估算等统计侧能力

## Further Notes

- 本次讨论明确否决了渠道分区：用户确认单 baseUrl 单 key 下渠道是纯复杂度；若未来出现同供应商多凭证需求，另起渠道分区 spec（已有 supplier-channel-models spec 可作起点）
- 术语沿用项目 glossary：供应商 / 网关，不新增术语；无 ADR（可逆展示改动，无需记录）
- 无 seam 争议：展示层单点改动，无需新增测试 seam
