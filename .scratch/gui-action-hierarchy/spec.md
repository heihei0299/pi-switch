# GUI 导航与操作层级整理（第一版）

日期：2026-10-18
设计状态：讨论范围已获用户确认
实现状态：未开始；本次仅记录设计，不包含 GUI 实现或功能验收

## 问题与目标

用户反馈 GUI「各种按钮太多，又多又杂」。本次目标是让常用操作显眼、低频操作按用途分层，而不是换皮肤、删除功能或重写整个 GUI。

当前工作树代码中可确认的现象（不是实际窗口验收）：

- `desktop/native_standard.go`：11 个导航入口排成四行，`Profiles` 与 `Providers` 实际使用同一页面。
- `desktop/native_overview_controller.go`、`desktop/native_standard.go`：总览与独立 Proxy 页面都展示代理控制。
- `desktop/native_providers.go`、`desktop/native_provider_operations.go`：列表、预设、JSON 编辑及多个辅助操作集中在同页；进入编辑后同时显示测试、用量刷新、模型获取、复制、校验、保存及删除等操作。
- `desktop/native_proxy.go`：启动、停止、刷新状态三个按钮同时呈现。

## 已确认的设计

### 1. 导航去重与分层

取消顶部四排平铺按钮，保留四个主要页面和一个分开的维护入口：

- 总览：当前供应商摘要、切换入口与代理状态控制。
- 供应商：合并现有 `Profiles` / `Providers`，提供查找、选择、添加与编辑。
- 网关：模型选择、发布预览与显式发布。
- 用量与会话：保留现有统计及会话能力。
- 设置与维护：以二级页面或分组容纳设置、软件包、备份与恢复、诊断、高级 JSON 编辑。

代理日常控制归入总览，不再占用独立一级导航入口。维护区必须按用途组织，不把全部按钮塞进一个无分组的“更多”菜单。上述中文名称用于说明页面职责，不要求本次额外完成全应用汉化。

### 2. 总览聚焦日常任务

- 正常状态优先展示当前供应商摘要和代理状态，突出切换入口。
- 配置路径、完整连接细节与调试说明不常驻占据主区域，需要时仍可查到。
- 代理根据真实状态突出当前适用的操作，不同时突出相反的启动和停止动作；状态未知时提供检查入口，不能当作已停止。
- 已有刷新能力保留为次要操作；本次不要求增加后台轮询或改变刷新机制。
- 错误、身份异常、待发布等需要处理的事项仍有明确提示，不能为了界面干净而隐藏。

### 3. 供应商列表与编辑任务分开

- 列表负责查找和选择，提供清晰的添加及进入所选项编辑的入口，不常驻铺开编辑工具。
- 预设作为添加流程的一部分，不与列表上的日常操作并列堆放。
- 编辑时突出保存与取消；保留现有 JSON 编辑能力，只在相应添加或编辑任务中展示。
- 连接测试、模型获取、用量查询、复制及手动校验按目的归入次要操作区，按需展开；保留草稿操作与已保存配置操作的区别。
- 删除放在单独的危险操作区，保留现有确认流程。
- 收起手动校验入口不等于取消保存前验证。导航、收起区域或切换编辑任务都不能静默丢弃尚未保存的修改。

### 4. 第一轮不重做编辑器

保留现有 JSON、草稿与业务操作能力，不同时新建一套供应商表单编辑器。先验证导航与操作层级整理是否解决主要混乱；编辑器本身的易用性若仍有问题，再单独讨论。

## 不可弱化的边界

- 供应商配置与网关发布保持分离；保存供应商或设置不能隐式发布网关。遵守 `docs/adr/0006-supplier-gateway-logical-isolation.md` 与 `docs/adr/0011-canonical-system-contract.md`。
- 网关模型选择、预览、冲突提示及发布确认保持可达；发布仍是明确的用户操作。
- 代理状态不得只凭 PID 文件判断；只能停止身份已核验的受管进程。状态未知、身份不符或端口占用不能冒充正常状态或被接管。
- 删除、恢复备份等危险操作保留后果说明与确认；精简布局不修改已有安全语义。
- 错误、进行中状态、操作结果、无效 JSON 提示与未保存修改不能被静默隐藏或丢弃。
- 凭据遮蔽、键盘可达性、焦点和输入法保护继续有效。

## 范围之外

- 不删除现有业务能力，不调整配置或数据库格式，不改变网关发布、供应商保存、统计查询或代理生命周期的业务契约。
- 不新增 UI 依赖、主题系统、后台轮询或其他无关机制，不同时重写编辑器。
- 不迁移或重写历史规格，不把既有未提交改动混入本任务。
- 这些布局决定可逆，不单独创建 ADR；本次也没有新增需要记录的领域术语，不为凑文档创建词汇表。

## 后续实现的验收标准

1. 一级导航为四个主要页面及分开的设置与维护入口，不再出现四排按钮或重复的 `Profiles` / `Providers` 入口。
2. 总览能完成查看当前供应商、切换与适用的代理状态操作；辅助详情不挤占主要区域，异常提示仍明确可见。
3. 供应商列表不同时展开全部编辑工具；编辑任务突出保存与取消，辅助操作及危险操作分组清晰、仍可访问。
4. 网关、统计与会话、软件包、设置、备份恢复、诊断及 JSON 编辑能力均有可达路径，不因入口调整丢失功能。
5. 未知代理状态、身份核验失败、发布冲突、无效 JSON、取消编辑、删除和恢复确认等边界保持正确；不因导航或分组调整丢失草稿。
6. 实现时只运行直接受影响范围的现有测试并补充必要回归；实际 Native 窗口检查导航、键盘操作和布局，记录总览、供应商列表/编辑及维护区截图。源码检查或 HTML 结构草图不能当作 Native GUI 或真实硬件验收。
