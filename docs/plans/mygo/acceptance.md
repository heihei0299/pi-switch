# MyGo 简化验收计划

> 只测当前改动，不再要求每个工作包完成 AT-01～AT-18 全套测试。旧 WP 文档中的 AT 编号仅用于定位相关功能，不表示全部必须执行。

## 每项任务（必需）

1. **编译或相关测试通过**：只运行改动模块的测试，不重复跑整个仓库。
2. **功能可用**：实际操作本次修改的功能，确认预期结果。
3. **危险操作额外验证一次**：仅涉及配置写入、Gateway 发布、数据库、Proxy 启停或密钥/授权时，用临时路径和假数据确认不会误写、误停或越权。

完成后只记录：做了什么、运行的命令、结果、未测试项。一个任务一次验证后提交；无需截图、性能报告、完整测试矩阵。

## 整合与发布（延后执行）

- **阶段结束**：只回归受影响部分。Go 服务变化跑相关 Go 测试；WebUI 变化跑前端测试；桌面变化手动确认能启动、关键操作正常、退出不影响独立 Proxy。
- **准备合并 main**：运行仓库现有完整 CI，人工检查一次「供应商 → Gateway 预览/显式发布 → Proxy → 统计」。历史已有通过的用例不因文档更新而重做。
- **准备发布桌面包**：仅对准备声称支持的平台进行 GUI、安装/卸载测试。未测平台明确写“未验证”，不强制提前覆盖 Windows、Linux 和 macOS。
- 完全原生 UI 及旧前端退役不在当前阶段强制验收；只有实际实施时才测试对应页面功能。

## 旧 AT 编号如何使用

| 原编号 | 现在何时需要 |
| --- | --- |
| AT-01、AT-17、AT-18 | 合并/发布时检查 CI、构建和安全扫描 |
| AT-02～AT-04 | 实际修改供应商、模型或 Gateway 时 |
| AT-05～AT-07 | 实际修改 Proxy、流式处理、统计时 |
| AT-08～AT-10 | 实际修改进程管理、桌面绑定或授权时 |
| AT-11～AT-15 | 修改对应桌面 UI 时，只在当前开发环境检查；跨平台和性能测试不作为普通任务门槛 |
| AT-16 | 实际改动安装、升级、卸载或数据格式时 |

**始终不允许**：覆盖用户数据、自动发布 Gateway、关桌面误杀 Proxy、泄露密钥或开放未授权调用。涉及这些边界的变更不能跳过相关隔离验证。
